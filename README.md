# Screeps Arena Tutorial

This repository contains example code for the tutorial levels of [Screeps: Arena](https://store.steampowered.com/app/1137320/Screeps_Arena/), a programming strategy game where players write JavaScript/TypeScript code to control units for resource gathering and warfare.

## Overview

This project provides working implementations for all ten tutorial levels in Screeps: Arena. Each tutorial directory contains a complete solution with TypeScript type definitions to help developers learn the game mechanics and API.

## Tutorial Levels

The repository includes the following tutorial levels:

1. **tutorial-loop_and_import** - Introduction to the game loop and importing modules
2. **tutorial-simple_move** - Basic creep movement mechanics
3. **tutorial-harvest_energy** - Energy harvesting from sources
4. **tutorial-store_and_transfer** - Resource storage and transfer operations
5. **tutorial-spawn_creeps** - Creating new creeps from spawns
6. **tutorial-creeps_bodies** - Understanding and customizing creep body parts
7. **tutorial-first_attack** - Basic combat mechanics
8. **tutorial-terrain** - Working with terrain types
9. **tutorial-construction** - Building structures and construction sites
10. **tutorial-final_test** - Comprehensive final challenge combining all mechanics

## Structure

Each tutorial directory contains:
- `main.mjs` - The main implementation file
- `jsconfig.json` - JavaScript configuration for the module
- `typings/` - TypeScript type definitions for game API

## Usage

These examples can be used as reference implementations or starting points for your own Screeps: Arena code. Each tutorial is self-contained and can be studied independently.
